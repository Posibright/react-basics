Classes: An object creation template.  They use a constructor method for initialization and inheritance, and they encapsulate data with code to work on that data.

 Arrow Functions: A shorter syntax for expressing functions.  They are perfect for non-method functions because they lack their own this, arguments, super, and new.target.


 Variables: Identified data value storage containers.  declared with var, let, or const; let and const are block-scoped, while const is used for values that shouldn't be changed.

 Array methods are built-in functions that array objects can use to carry out common tasks, such as filtering (.filter()), reducing to a single value (.reduce()), or iterating (.map(),.forEach()).

 Destructuring: Using a simple syntax, this method makes it easy to extract values from arrays or properties from objects into separate variables.

Modules: A technique to organize code by dividing it into manageable, independent files (.js) that can import and export functionality (such as variables or functions).

An if...else statement can be shortened with the ternary operator, a conditional operator. Three operands are required: an expression for true, an expression for false, and a condition (condition? expression_if_true : expression_if_false).

The spread operator, denoted by three dots (...), copies all properties from one object to another or expands an iterable (such as an array or string) into its component parts.
